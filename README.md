# مِنهَاج | Minhaj

منصة تعليمية لطلاب التوجيهي، مع مصادر مرتبة، تأسيس، حلول، بطاقات تعليمية، وحسابات طلاب.

## بطاقات الطالب

صفحة **بطاقاتي** تسمح للطالب المسجل بإنشاء مجموعات بطاقات شخصية، إضافة وتعديل وحذف البطاقات، وإنشاء رابط مشاركة لمجموعة كاملة. صفحة المشاركة تسمح لأي شخص بقراءة المجموعة ونسخها إلى حسابه.

البيانات الشخصية للبطاقات محفوظة في Firestore ضمن `studentFlashcardSets/{setId}`، والمشاركة العامة ضمن `studentFlashcardShares/{setId}`.
