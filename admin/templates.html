القوالب العامة

نظام قالب واحد لكل نوع محتوى: انسخه إلى ChatGPT مع بياناتك، ثم الصق JSON الناتج هنا لاستيراده.

طريقة الاستخدام

  1. اختر نوع المحتوى.
  2. انسخ القالب وأرسله إلى ChatGPT مع المصادر أو المعلومات.
  3. اطلب منه إخراج JSON مطابقًا للقالب فقط.
  4. الصق الناتج هنا واضغط «استيراد JSON».
  5. استيراد المصادر يفحص الرابط بعد تطبيعه ويتخطى الروابط المكررة بدل إنشاء نسخة ثانية.
